# v1.7 Milestone Decision — WAF-Proper (own-engine), first credible slice

**Date:** 2026-07-13 · **Author:** KanameMadoka520 · **Branch:** `open-pro-v1` (base v2.2.3)
**Design source of truth:** `.planning/research/WAF-ENGINE-DESIGN.md` (six-probe recon synthesis).

## Decision

Build a **real** community WAF: OWASP **Coraza v3** + **CRS v4 (PL1)** compiled into a dedicated loopback
reverse-proxy sidecar (`coraza-gateway`) that sits behind OpenResty's TLS termination. This is the
milestone the user **explicitly opted into** after it was deferred as XL in v1.6.

**Honesty red-line (W11):** the closed 1pwaf/OpenResty engine is entirely absent from the tree; its
filesystem-shim funcs (`createWafConfig`/`moveDefaultWafConfig`/`delWafConfig`) are **NOT** reused or
surfaced as a working WAF. The feature is a genuine engine or it is honestly OFF. `isProductPro`/license
is never fabricated; the per-site "protected" signal derives from real engine health.

## Open decisions — provisional defaults (proceeding unless the user overrides)

These bind mostly at Phases 21–23, **not** Phase 19, so Phase 19 proceeds now on the recommended defaults:

1. **CRS distribution:** **bundle** via `coraza-coreruleset` `embed.FS` (self-contained, CI-reproducible, no runtime network). *(optional operator-triggered update = LATER)*
2. **Default posture:** new sites **detection-only (labeled fail-open)**; block mode = **fail-closed**; never silent fail-open in protect mode (W1).
3. **Two-tier spine:** build global-default → per-site override in the slice (retrofitting is expensive).
4. **First enablement type:** **reverse-proxy sites only** first.
5. **nginx seam:** per-location `proxy/*.conf` include (opt-in safe, lifecycle reuse).
6. **WafProvider xpack seam:** carve a `WafProvider` stub mirroring `AlertProvider`/`MultiNodeProvider` so `/xpack/waf/*` resolves to a real open WAF with honest gating.
7. **Version label:** **v1.7** (not load-bearing).

## Status

Phase 19 is the immediate target (CI-verifiable, no live host needed). Live inline blocking is tracked as
human UAT debt (needs a real OpenResty site), consistent with prior milestones. No second VPS required for
Phases 19–20.
