# Phase 10 Plan 01: Branding Image Upload (backend + serve hardening)

**Requirement:** BRAND-IMG-01

## Steps

1. **`core/app/service/enhancement_asset.go`** (new)
   - `brandingAssets` map (fixed enum → `{settingKey, maxBytes, requirePNG}`); `allowedBrandingImageFormats` = png/jpeg/gif/webp.
   - `IsBrandingAssetFileName(name)` — exported, used by the serve route.
   - `SaveAsset(assetKey, data)`: enum check → non-empty → size cap → `looksLikeMarkup` reject → `DecodeConfig` (format whitelist + favicon-PNG + `≤16 MP`) → full `Decode` → atomic write → store sentinel.
   - `ResetAsset(assetKey)`: enum check → prefix-assert → `os.Remove` (ignore not-exist) → clear sentinel.
   - Helpers: `writeBrandingAssetFile` (temp+chmod+rename), `isWithinDir`, `looksLikeMarkup`, `brandingAssetDir`.
   - Side-effect decoder imports incl. `golang.org/x/image/webp`.

2. **`core/app/service/enhancement.go`**
   - `IEnhancementService`: add `SaveAsset`, `ResetAsset`.
   - `GetSettingInfo`: populate `Logo/LogoWithText/Favicon/LoginImage` sentinels.
   - `GetPublicSettingInfo`: add the same four (presence sentinels; T8).
   - `validateEnhancementSetting`: split `LoginBackground` (accept `""`/color/`"loginBackground"`) from `LoginBtnLinkColor`; add `Logo/LogoWithText/Favicon/LoginImage` → `validateBrandingAssetSentinel` (empty or `lowerFirstRune(key)`); keep fail-closed default.

3. **`core/app/dto/enhancement.go`**
   - Widen `PublicEnhancementSettingInfo` with `logo/logoWithText/favicon/loginImage`.
   - Add `EnhancementAssetReset{ Key oneof=logo logoWithText favicon loginImage loginBackground }`.
   - Do NOT add image keys to `EnhancementSettingUpdate.oneof`.

4. **`core/app/api/v2/enhancement.go`**
   - `UploadEnhancementAsset`: `MaxBytesReader` body cap → `FormFile("file")` → `PostForm("key")` → read bytes → `SaveAsset`.
   - `ResetEnhancementAsset`: bind `EnhancementAssetReset` → `ResetAsset`.
   - `enhancementAssetBodyLimit` const (2 MiB + slack).

5. **`core/router/ro_setting.go`**
   - In the authed `settingRouter` group: `POST /enhancements/asset`, `POST /enhancements/asset/reset`.

6. **`core/init/router/router.go`**
   - Rewrite `RegisterImages` (enum gate + `Lstat` regular-file + `sniffImageContentType` allowlist + `nosniff`, no `<svg>` override). Add `sniffImageContentType`.

7. **Tests** — `enhancement_asset_test.go` (new) + extend `enhancement_test.go`:
   - subset test: promote logo/logoWithText/favicon/loginImage to public presence sentinels; keep watermark/watermarkShow forbidden.
   - validator: image-sentinel accept/reject; LoginBackground image sentinel.
   - asset pipeline: happy path (file + sentinel written, no residue), jpeg/gif accepted, favicon PNG-only, SVG/XML/HTML rejected, non-image rejected, crafted huge-dimension PNG (pixel bomb) rejected with no file written, oversize bytes rejected, unknown key rejected, empty rejected, LoginBackground sentinel survives read-path, reset removes file + clears + idempotent + unknown-key rejected, `IsBrandingAssetFileName` enum.
