# Phase 09 Plan 01: Community Branding Form

**Requirement:** BRAND-02

## Steps

1. Investigate `frontend/src/views/setting/panel/index.vue` structure (it already calls `getXpackSetting(true)` and has a form model) to find the cleanest insertion point for a "Brand & Login" section, or add a small dedicated child component it renders.
2. Add inputs bound to the loaded form model:
   - `Title` (`el-input`, maxlength 64) → save `updateXpackSettingByKey('Title', v)`.
   - `MasterAlias` (`el-input`, maxlength 64) → `'MasterAlias'`.
   - `LoginBgType` (`el-select` image|color) → `'LoginBgType'`.
   - `LoginBackground` (`el-color-picker` shown when bg-type=color) → `'LoginBackground'`.
   - `LoginBtnLinkColor` (`el-color-picker`) → `'LoginBtnLinkColor'`.
3. On save, surface backend validation errors (the request rejects invalid values). Show success via `MsgSuccess`.
4. Reuse/add i18n labels (zh + en) under the existing branding namespace.
