# Phase 11 Plan 01: Branding Image Form (frontend)

**Requirement:** BRAND-IMG-02

## Steps

1. **`frontend/src/api/modules/enhancement.ts`**
   - `uploadOpenEnhancementAsset(key, file)` → `FormData{key,file}` via `http.upload('/core/settings/enhancements/asset', fd)`.
   - `resetOpenEnhancementAsset(key)` → `http.post('/core/settings/enhancements/asset/reset', { key })`.

2. **`frontend/src/views/setting/panel/index.vue`**
   - Imports: `uploadOpenEnhancementAsset, resetOpenEnhancementAsset`; add `MsgError`.
   - `form`: add `logo/logoWithText/favicon/loginImage`.
   - `search()`: load the four from `xpackRes.data`.
   - Script: `previewTick`, `brandAssets` descriptor list, `assetValue(key)`, `assetPreviewUrl(key)`, `beforeAssetUpload(key,file)` (client size/type hint), `onUploadAsset(key,file)`, `onResetAsset(key)`.
   - Template: a `loginBackground` image uploader shown when `loginBgType==='image'` (preview/reset gated on the `loginBackground` sentinel); a `v-for` group of logo/logoWithText/favicon/loginImage uploaders. Each: preview `<img>` on presence, `el-upload` (`:show-file-list=false`, `:accept`, `:before-upload`, custom `:http-request`), reset button on presence. Help text per asset.
   - Style: `.brand-asset`, `.brand-asset__preview`.

3. **i18n** — `frontend/src/lang/modules/{en,zh}.ts` under `setting`:
   `brandImages, brandLogo, brandLogoWithText, brandFavicon, brandLoginImage, brandLoginBgImage, brandUpload, brandImageHelper, brandFaviconHelper, brandImageTooLarge, brandImageBadType`.
