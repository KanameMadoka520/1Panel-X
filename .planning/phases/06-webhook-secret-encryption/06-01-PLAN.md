# Phase 06 Plan 01: Webhook Secret At-Rest Encryption

**Requirement:** ALERT-SEC-01
**Approach:** Encrypt the webhook `url` at rest with the repo's existing `encrypt` helper; keep service-layer plaintext invariant; migrate existing rows.

## Steps

1. **`agent/utils/webhook_alert/secret.go`** (new)
   - `const webhookURLEncPrefix = "enc:v1:"`
   - `func IsEncryptedWebhookURL(v string) bool` — `strings.HasPrefix(v, prefix)`.
   - `func EncryptWebhookURL(plain string) (string, error)` — trim; empty→`""`; already-prefixed→return as-is (idempotent); else `enc:v1:` + `encrypt.StringEncrypt(plain)`.
   - `func DecryptWebhookURL(stored string) (string, error)` — no prefix→return as-is (legacy plaintext); strip prefix; empty→`""`; else `encrypt.StringDecrypt(cipher)`.

2. **`agent/utils/webhook_alert/secret_test.go`** (new) — pure unit tests that inject a key via a small seam. `encrypt.StringEncrypt` reads `global.CONF.Base.EncryptKey` (falls back to DB). Test sets `global.CONF.Base.EncryptKey` directly to a fixed 16+ char key so no DB is needed. Cases: roundtrip; empty; idempotent double-encrypt; legacy plaintext passthrough; ciphertext differs from plaintext; decrypt of prefixed-but-corrupt returns error.

3. **`agent/app/service/alert.go`**
   - Add `encryptWebhookAlertConfigURL(req *dto.AlertConfigUpdate) error` — if `isWebhookAlertConfigType(req.Type)`: unmarshal `dto.AlertWebhookConfig`; `cfg.Url, err = webhook_alert.EncryptWebhookURL(cfg.Url)`; marshal back into `req.Config`. Call it in `UpdateAlertConfig` after `checkAlertConfigSMSPhoneUnique` (line ~524), before the `if req.ID != 0` persist branch — covers both create and update at one site.
   - In `replaceMaskedWebhookURL`: after reading `stored`, set `incoming.Url, err = webhook_alert.DecryptWebhookURL(stored.Url)` (instead of the raw assignment), so validation + re-encryption see plaintext. Keep the empty-URL guard on the decrypted value.

4. **`agent/utils/xpack/helper/alert.go`** `createWebhookAlertLog`
   - After `json.Unmarshal(&webhookConfig)` succeeds, decrypt: `if url, dErr := webhook_alert.DecryptWebhookURL(webhookConfig.Url); dErr != nil { deliveryErr = dErr } else { webhookConfig.Url = url }`. Only send when `deliveryErr == nil`. On decrypt failure, the existing error-logging branch records it (no plaintext leak).

5. **`agent/init/migration/migrations/init.go`** — add:
   ```go
   var EncryptWebhookAlertConfigURL = &gormigrate.Migration{
       ID: "20260711-encrypt-webhook-alert-config-url",
       Migrate: func(tx *gorm.DB) error {
           var configs []model.AlertConfig
           if err := global.AlertDB.Model(&model.AlertConfig{}).
               Where("type in ?", []string{constant.WeCom, constant.DingTalk, constant.FeiShu}).
               Find(&configs).Error; err != nil { return err }
           for i := range configs {
               var cfg dto.AlertWebhookConfig
               if err := json.Unmarshal([]byte(configs[i].Config), &cfg); err != nil { continue }
               if cfg.Url == "" || webhook_alert.IsEncryptedWebhookURL(cfg.Url) { continue }
               enc, err := webhook_alert.EncryptWebhookURL(cfg.Url)
               if err != nil { return err }
               cfg.Url = enc
               data, err := json.Marshal(cfg)
               if err != nil { return err }
               if err := global.AlertDB.Model(&model.AlertConfig{}).
                   Where("id = ?", configs[i].ID).Update("config", string(data)).Error; err != nil { return err }
           }
           return nil
       },
   }
   ```
   Register in `migrate.go InitAgentDB` list (append after `InitFirewallPortWhiteList`). Add imports (`encoding/json`, `dto`, `constant`, `webhook_alert`) if the file lacks them.

6. **`agent/app/service/alert_webhook_config_test.go`** (extend) — add: create webhook config → stored `config` url has `enc:v1:` prefix and decrypts to the input; masked list still returns `********`; edit with masked url keeps the original stored secret (decrypts equal); migration function encrypts a seeded plaintext row once and is idempotent on a second run.
