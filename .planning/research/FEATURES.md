# 功能边界研究

**原则：** 只依据官方公开仓库、公开交互文案、生成 API/操作清单和开放协议独立实现，不读取或复制闭源模块。

## 已公开且不应重复开发

- Docker、网站、数据库、文件、计划任务、备份、主机监控等社区核心能力。
- GPU 监控当前已经位于公开代码和默认菜单中，README 的旧版商业说明已滞后。
- WAF 的基础全局/站点开关不是整体付费；商业差异主要是统计、日志、封锁、ACL、地理限制和自定义页面。
- 邮件和 Bark 告警已在社区实现，商业差异是企业微信、钉钉、飞书和短信。

## P0 首版

| 能力 | 用户结果 | 复杂度 | 实现状态 |
|---|---|---:|---|
| 自定义主题与水印 | 社区构建可保存主题色、深浅色方案和登录后水印，刷新后仍生效 | 中 | 本轮实现 |
| 开放 Webhook 告警 | 可配置企业微信、钉钉、飞书机器人并记录成功/失败日志 | 中 | 本轮实现 |
| 定时 ClamAV | 扫描规则可设置周期、启停、重启恢复并触发现有告警 | 中 | 本轮实现 |
| 无限 AI Agent | 不再存在版本绑定的 5 个硬上限，可选软限制默认 0 | 低 | 本轮实现 |

## P1 核心增强

- WAF 日志、趋势、攻击地图、封锁记录、ACL、IP/地区组和导出。
- 网站 PV/UV/IP/QPS/流量、来源、设备、URI 排名和请求日志监控。
- 多节点安全接入、节点切换、分组、升级、健康状态与基础资源总览。
- 文件、镜像、SSL 证书和应用依赖同步。
- RBAC 基础：用户、角色、节点范围、查看/管理权限和 API 白名单。
- 自定义应用仓库、系统代理增强、模型下载器和 vLLM 管理。

## P2 运维增强

- 网站防篡改、保护/排除规则、审计和恢复联动。
- 多节点资源总览、应用迁移和智能体批量运维。
- 运维报表、安全评分、历史和定时导出。
- Skills Hub 导入、静态扫描、审核、版本和节点安装。
- AI 基准测试与基础 AI 网关。

## P3 高风险/独立产品

- MySQL/PostgreSQL/Redis 高可用、故障切换和脑裂处理。
- 完整 AI 网关智能路由、内容审计、Token 计量与 Elasticsearch 链路。
- KVM/libvirt 虚拟机、网络、存储、VNC、快照和模板。
- 移动客户端或 PWA。
- AI 建站 Upage。当前公开代码仅跳转外部 SaaS，必须重新定义本地产品契约。
- 短信服务。必须接入自有供应商、额度、隐私和合规模型。
