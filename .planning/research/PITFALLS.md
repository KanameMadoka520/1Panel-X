# 风险与陷阱研究

## 通用

- 不得通过强制 `isProductPro` 暴露缺失页面；功能必须逐项注册。
- 不得以“接口存在”视为“功能完成”；必须有行为测试和 VPS UAT。
- 公开生成的 Swagger/x-log 是接口证据，不是闭源实现源码。
- 新设置要校验写入值，也要校验数据库已有值并在损坏时回退。

## 主题与水印

- 公开登录接口不能返回包含节点名、客户名的水印内容。
- 社区主题函数原本是 no-op，必须直接更新 CSS 变量。
- 水印开关不应替换整棵路由 DOM，否则会丢失未保存状态。
- 需验证深色、浅色、系统主题、刷新、新标签页和移动端。

## Webhook

- 不得继承 `InsecureSkipVerify=true` 的节点 Transport。
- 仅允许 HTTPS 和对应平台官方机器人域名，禁止重定向。
- URL 含机器人密钥，错误、日志和 API 响应不得泄漏完整地址。
- 失败也要形成 Error 日志和发送尝试计数，避免无限重试。
- 首版不开放短信；短信需要独立供应商和合规设计。

## ClamAV

- 创建必须先得到数据库 ID，再注册回调。
- 更新应先验证/注册新规则，成功后再移除旧 Entry。
- 重启必须恢复所有 Enable + 非空 Spec 规则。
- 手工和定时扫描必须防重入；高频规则不能并发耗尽主机。
- 扫描路径、隔离路径、名称和删除目标必须规范化并做包含关系检查。
- 隔离目录权限应为 0700，不得使用 0777。
- `remove` 策略只能在隔离测试目录做 UAT。

## AI Agent

- 无限数量不代表无限资源；仍需端口、磁盘、内存和 Docker 网络检查。
- 软限制的 Count + Create 不是原子操作，并发可能越界。
- 应确认 App Store 元数据没有第二层 `App.Limit`。
- 安装后 Agent 记录写入失败时应清理孤儿容器和应用记录。

## 阶段映射

| 风险 | 阶段 |
|---|---|
| 主题实际生效、公开数据拆分 | P0 |
| Webhook TLS/SSRF/失败计数 | P0 |
| Clam 调度顺序、恢复、防重入、路径安全 | P0 |
| AI Agent 默认无限语义 | P0 |
| Webhook 密钥加密、测试按钮、消息长度 | P1 |
| 多发行版 Clam/EICAR 验证 | P1/P2 |
| WAF、多节点、RBAC、VM 的真实 VPS 集成 | 各自阶段必需 |
