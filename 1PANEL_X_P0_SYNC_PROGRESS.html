01 / Executive Summary

执行摘要

30-60 秒结论：v2.2.4 已形成可测试的新基线，P0 安全边界未被官方更新覆盖；除已记录的全仓 TypeScript 基线债务外，本轮验证通过。

Progress

官方 v2.2.4 的 Core、Agent、前端与文档改动已通过普通 merge 审查；持久化 outbox、单调 revision、Agent 幂等应用、tombstone、离线 reconciliation、同步状态 API、执行租约和 OAuth 隔离均保留。 Redis、cron snapshot、OneDrive 与 pending Action 的阻断问题已经修复并加入自动测试。

Plans

Problems

02 / Merge Flow

合并与安全收口流程

只吸收官方正式版，以 1Panel-X 已有安全边界为约束处理冲突；不恢复托管自动化、共享 OAuth 凭据或浏览器敏感状态。

STEP 1 锁定正式版父项

以 1Panel-X 85e17a988 和官方标签 v2.2.4 对应提交为两个 merge parent。

STEP 2 逐项保留 P0

检查 outbox、revision、幂等、tombstone、reconciliation、同步状态、执行租约和 OAuth API 脱敏。

STEP 3 手工吸收 Graph 改进

保留官方 Graph API 能力，但拒绝重定向、跨源分页和 signed URL 泄漏，secret 仅进入服务端 POST form。

STEP 4 修复执行竞态

Redis 备份/恢复只执行一次；超时 Action 不与重试或回滚重叠，失败清理不重跑已完成备份。

STEP 5 全量验证与卫生检查

执行 Core/Agent 全量测试、race、vet、迁移、前端测试和 Linux 构建，并清理生成物后再提交。

Redis 恰好一次执行

  • parent task 路径只注册子任务，不再立即重复执行。
  • standalone backup/recover 只注册一次并只启动一次 Execute。
  • 恢复模式在停容器前冻结；失败回滚不再向已停止的 Redis 查询配置。
  • 主恢复和回滚均失败时返回脱敏 non-retryable 错误，并保留预恢复备份供人工恢复。
已完成

任务超时与取消收口

  • 每次 Action 接收继承 root cancel/deadline 的独立 TaskCtx。
  • 超时后先等待有界停止宽限期，旧 Action 未退出时绝不重试或回滚。
  • 后台业务 worker 等待唯一 finalizer 完成后，才释放锁、清理文件或更新业务记录。
已完成

备份清理保持 non-retryable

  • 每次外层重试只发起一次 provider 上传，避免 RetryTimes 被内层循环放大。
  • 元数据落库失败会回滚所有已确认创建的远端目标。
  • cron snapshot 多账户落库失败会逐对象删除并用 Exist 确认，不留下无记录快照。
  • 清理状态未知时返回 non-retryable，避免重新执行整份已成功备份。
  • 本地失败产物删除限制在备份根目录内，拒绝绝对路径和目录逃逸。

05 / Security

OAuth 与 OneDrive 安全边界

官方 Graph 改进只在服务端/受控 Agent 内吸收；浏览器读取 API 和 UI 状态继续不含 client secret、refresh token 或内部同步元组。

浏览器可见信息

  • provider、configured 与迁移/重新授权状态
  • 安全展示的 client ID 与更新时间
  • accountName
  • status
  • succeeded
  • pending
  • total

禁止离开服务端的内容

  • client secret、refresh token、密文与旧默认应用完整值
  • authority、generation、target epoch、snapshot digest
  • target key、节点 ID/名称、desired/applied revision
  • signed URL/query、provider 原始错误与跨源 Graph nextLink
06 / Risks & Rollback

风险、迁移与回滚

本轮是普通 merge，可通过 revert merge 回退代码；但 v2.2.4 与 P0 数据库迁移已执行的环境仍应先备份 Core/Agent 数据库再降级。

环境缺口

真实环境 UAT

仍需演练节点断网/恢复、Core/Agent 重启、删除 tombstone、revoke、重注册与滚动升级。

Provider 缺口

真实 OAuth 备份

仍需隔离 Microsoft Entra 与 Google Cloud 测试应用验证授权、刷新、上传、下载和撤销。

回滚注意

数据库降级不是自动回滚

降级前应停止公共账号和备份任务变更并备份数据库；旧二进制不理解新增 outbox、target epoch、租约或 v2.2.4 schema。

维护项

超时 Action 的延迟收尾

若底层 Action 完全忽略 context，前台异步请求不被长期占用，但任务、业务状态和执行锁保持 Executing；只有 Action 退出后才回滚、清理和关闭日志。永久不退出时需要运维确认或重启，系统不会自动并发重试。

安全债务

依赖审计仍需单独维护

npm ci 报告 5 项依赖告警；本轮没有运行可能升级大版本或改写 lockfile 的自动修复，应独立评估后处理。

仓库基线

全仓 TypeScript 债务

生产构建可通过，但全仓 type-check 非绿色；建议单独清理，使未来类型检查能成为硬门禁。

不在本轮

dev-v2 与完整 Pro parity

本轮只形成 v2.2.4 + 既有 P0 的稳定基线；正式版后的 dev-v2 提交需另行审计，不能表述为完整复刻专业版。
