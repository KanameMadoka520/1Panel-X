01 / Executive Summary

执行摘要

30-60 秒结论：本轮目标已达到代码级交付标准，但没有把自动测试等同于真实生产环境 UAT。

Progress

Core 以数据库 outbox 和单调 revision 管理公共备份账号期望状态；每个 Agent 持久化最近应用的 authority、generation、target epoch、revision 和 digest，重复、乱序与重启后仍可收敛。

Plans

下一步应在可回滚 Linux 环境中演练真实 Core + 多 Agent 断网、重启、删除与恢复，并使用隔离的 Microsoft Entra 和 Google Cloud 测试应用确认 OAuth 备份实际执行链路。

Problems

当前没有可登录的完整多节点部署，因此尚无浏览器网络面板与真实节点级证据。全仓 vue-tsc 仍被本轮范围外的既有错误阻断；snapshot digest 目前是内部 unkeyed SHA-256， 不是 HMAC。

02 / State Flow

同步机制

敏感凭据不写入 outbox。Core 在投递时从加密源表构建完整快照，经 Unix socket 或固定证书 mTLS 发送。

STEP 1 业务事务提交

创建、更新、删除、OAuth 清除或刷新与 revision 在同一事务提交；outbox 失败则业务回滚。

STEP 2 持久化协调状态

outbox 只含 generation、revision、账号名、操作和状态；每个 target 保留 desired/applied 元组。

STEP 3 有界并行投递

最多四个不同目标并发，同一目标串行；内存 wake 仅加速，数据库状态负责重试和重启恢复。

STEP 4 Agent 原子应用

校验 authority、generation、target epoch、revision 和 digest 后，在单事务替换公共账号快照。

STEP 5 精确 ACK 与完成

Core 只接受精确元组 ACK；全部活动目标确认后才完成 outbox 并关闭删除 tombstone。

03 / Delivered

已交付能力

以下是本轮真实实现的行为，不表示已经完成完整 1Panel Pro 或 Enterprise 功能对齐。

已完成

持久化 outbox 与 revision

  • 安装级 authority、generation 和 uint64 revision。
  • 并发入队保持 revision 唯一、单调，事务回滚不遗留事件。
  • 启动 bootstrap reconciliation，待同步状态可跨进程重启。
已完成

Agent 幂等与乱序保护

  • 相同元组可重复应用并返回 already_applied。
  • 旧 revision 不覆盖新状态，相同 revision 不同 digest 被拒绝。
  • authority、generation 或 target epoch 冲突时 fail-closed。
已完成

删除 tombstone

  • 删除元数据保留到所有活动目标确认删除 revision。
  • 离线节点重新上线后仍会收到删除快照。
  • 被 revoke 或删除的节点停用 target，不会永久阻塞完成条件。
已完成

离线 reconciliation

  • 每分钟扫描到期 target，并允许探测标记 offline 的已登记节点。
  • 同步成功后仅在节点仍是 offline 且已登记时标记 online。
  • 明确 offline 不阻止 tombstone；online 但不可达继续 fail-closed。
已完成

聚合 API 与界面

  • 浏览器只收到账号名、状态与 succeeded/pending/total。
  • 显示 sync_pending、partially_synced 与单账号/批量重试。
  • 未知状态或接口异常不伪装为成功。
已完成

执行与清理 fail-closed

  • 公共账号必须持有新鲜五分钟同步租约。
  • 同步 apply 与实际存储操作通过读写锁串行。
  • 远端删除未确认时保留记录/快照元数据，不重跑已完成备份。

05 / Security

浏览器与内部通道边界

内部快照含执行所需凭据，但浏览器读取 API 和 UI 状态不含 secret、token、内部节点信息或 revision。

浏览器允许字段

  • accountName
  • status
  • succeeded
  • pending
  • total

浏览器禁止字段

  • client secret、refresh token、ciphertext
  • authority、generation、target epoch、snapshot digest
  • target key、节点 ID/名称、desired/applied revision
  • attempts、内部错误、重试时间和成功时间
06 / Risks & Rollback

风险、迁移与回滚

迁移新增协调状态表，不删除既有备份账号、任务、记录或历史；但旧二进制不理解新协议。

环境缺口

真实多节点 UAT

仍需演练节点断网、Core/Agent 重启、删除账号、节点恢复、revoke、重注册和滚动升级。

Provider 缺口

真实 OAuth 备份

仍需隔离 Microsoft Entra 与 Google Cloud 测试应用验证授权、刷新、上传、下载和撤销。

回滚注意

旧版本不消费新状态

降级前应停止公共账号变更并备份 Core/Agent 数据库；旧版本不会消费 outbox、target epoch 或租约。

维护项

outbox 长期保留

完成事件当前保留用于审计；未来可增加按 revision 或时间窗口的安全压缩，避免无限增长。

安全债务

digest 不是消息认证码

它不返回浏览器，通道由 Unix socket/mTLS 保护。若要抵抗内部摘要泄露后的低熵猜测，需先设计密钥轮换再升级 HMAC。

仓库基线

全仓 TypeScript 债务

生产构建可通过，但全仓 type-check 非绿色；建议单独清理，使未来类型检查能成为硬门禁。

不在本轮

完整 Pro parity

本轮只完成公共备份账号一致性层 P0.1，不应表述为完整复刻专业版。
